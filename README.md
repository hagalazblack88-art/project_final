# 🚀 LiveJ - Fullstack Social Platform

Современная полнофункциональная социальная платформа, разработанная с использованием клиент-серверной архитектуры и полностью контейнеризированная с помощью Docker.

## ✨ Основные возможности

- 🔐 **Аутентификация и авторизация:** Регистрация, вход/выход, JWT-токены и безопасное хранение сессий через HTTP-only cookies.
- 📝 **Посты:** Создание, просмотр и управление публикациями.
- 👥 **Сообщества (Группы):** Создание групп, просмотр ленты сообществ.
- 💬 **Комментарии:** Система комментирования постов.
- 👤 **Профили пользователей:** Просмотр профиля, статистики, активности и возможность редактирования имени.

## 🛠️ Технологический стек

**Backend:**
- Python 3.12
- FastAPI (асинхронный веб-фреймворк)
- SQLAlchemy + Alembic (ORM и миграции)
- `fastapi-users` (готовое решение для аутентификации)
- SQLite (легковесная база данных)

**Frontend:**
- React 18 + TypeScript
- Vite (быстрая сборка и HMR)
- Axios (HTTP-клиент)

**DevOps & Инфраструктура:**
- Docker & Docker Compose (контейнеризация)
- Nginx (раздача статических файлов фронтенда в production)

## 📋 Предварительные требования

Для запуска проекта на вашем компьютере необходимо установить только одно:
- [Docker Desktop](https://www.docker.com/products/docker-desktop/) (включая Docker Compose)

*Никакой ручной установки Python, Node.js или баз данных не требуется!*

## ⚡ Быстрый старт

1. **Склонируйте репозиторий и перейдите в папку проекта:**
   ```bash
   git clone https://github.com/hagalazblack88-art/project_final.git
   cd project_final
2. **Настройте переменные окружения.**
   Создайте в корневой папке файл .env и добавьте в него следующие строки:
   ```env
   DATABASE_URL=sqlite+aiosqlite:///./data/db.sqlite3
   SECRET_KEY=your_super_secret_key_change_this_in_production
3. **Запустите проект.**
   Эта команда автоматически соберёт образы, создаст структуру базы данных и запустит все сервисы в фоновом режиме:
   ```bash
   docker compose up --build -d
4. **Откройте приложение в браузере:**
-  🌐 Основной сайт: http://localhost
-  ⚙️ API документация (Swagger): http://localhost:8000/docs
-  📂 Исходный код: GitHub Репозиторий

## 🐳 Полезные команды Docker
-  Просмотр запущенных контейнеров: docker ps
-  Просмотр логов бэкенда (в реальном времени): docker logs livej_backend -f
-  Полная остановка проекта: docker compose down
-  Полная очистка (включая базу данных): docker compose down -v
